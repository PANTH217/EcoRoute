# 🌍 EcoRoute Optimizer - Enterprise ESG Logistics Engine

### 🚀 Optimizing Every Mile for a Greener Tomorrow
**EcoRoute Optimizer** is an advanced logistical orchestration platform designed to minimize carbon emissions, reduce operational costs, and maximize asset utilization through AI-driven routing and real-world data integration.

---

## ✨ Key Features

### 🧠 Gen-AI Route Analyst
A sophisticated "Logistics LLM" analyst that provides executive-level strategic summaries for every route.
- **Payload-Aware Logic**: Analyzes the impact of specific weights (e.g., 20 Tons) on fuel physics and gradient efficiency.
- **Strategic Briefings**: Generates human-readable explanations of *why* a specific route was chosen as the "Best Eco" option.

### 🎙️ Magic Dispatch (NLP Logistics)
Transform plain text commands into logistical actions. Simply type:
> *"Send a 12T truck from Surat to Mumbai with pharmaceutical cargo."*
The system automatically parses the locations, vehicle requirements, and cargo types to trigger optimal routing.

### 🔄 Backhaul Return Trip Optimization
Eliminate "Empty Miles" by automatically identifying high-value cargo matches for returning vehicles.
- **Marketplace Integration**: Simulates a live freight marketplace within the route execution flow.
- **Customizable Multi-Node Logic**: Designed for warehouse managers to coordinate cargo pick-ups across different supply chain nodes.

### 📊 Enterprise ESG Dashboard
A comprehensive analytics suite for sustainability auditing:
- **Carbon Abatement Tracking**: Real-time monitoring of CO2 savings.
- **Dynamic Pollutant Analysis**: Visualizing NOx and PM emissions across multi-modal alternatives.
- **One-Click ESG Reports**: Professional PDF export for corporate sustainability reporting.

## 🔬 The Math & Defense (Judge-Ready)
EcoRoute is built on rigorous, verifiable mathematical frameworks:
- **Haversine Geodesic Matrix**: Precision distance calculation using OSRM nodes.
- **Payload-Adjusted Fuel Physics**: ARAI benchmarks with a +3% rolling resistance penalty per ton of payload.
- **EPA/GHG Protocol Standards**: Industry-standard emission factors for CO2e calculation.
- **60/20/20 ESG Weighting**: A proprietary multi-objective ranking algorithm balancing Sustainability (60%), Cost (20%), and Efficiency (20%).

## 📦 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/YourUsername/EcoRoute-Optimizer.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment Variables**
   Create a `.env` file in the root:
   ```env
   VITE_GEMINI_API_KEY=your_gemini_key
   VITE_FIREBASE_API_KEY=your_firebase_key
   ```

4. **Run Development Server**
   ```bash
   npm run dev
   ```
